Features

Everything needed for AI EPUB translation.

A simple workflow for translating complete ebooks without manually extracting, translating and rebuilding EPUB files.

🤖

OpenRouter LLMs

Translate ebooks using modern AI models available through the OpenRouter API.

📚

Chapter Selection

Translate an entire EPUB book or select only the chapters you need.

🔍

Translation Preview

Preview translated text before committing to a complete ebook translation.

📖

Bilingual EPUB

Export an EPUB containing both original and translated text for comparison or language learning.

⏯

Pause & Resume

Pause long-running translation jobs and resume them later without restarting the entire book.

🐳

Docker Ready

Run EPUB Translator locally with a clean, reproducible Docker deployment.

Workflow

From EPUB to translated ebook.

STEP 01

Upload EPUB

Select the ebook you want to translate.

STEP 02

Choose AI Model

Select an OpenRouter LLM and translation languages.

STEP 03

Translate

Preview the output and translate selected chapters or the full book.

STEP 04

Download EPUB

Export bilingual or translated-only EPUB output.
